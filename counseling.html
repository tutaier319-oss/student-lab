학교생활, 무엇이 궁금한가요?

수강신청부터 기숙사까지, 궁금한 내용을 질문해 보세요.

학생상담 도우미

학번·연락처 등 개인정보는 입력하지 마세요. 실제 연동 시 질문은 설정된 n8n 서버로 전송됩니다.

이용 안내

먼저 확인해 주세요

답변은 수업용 예시 안내입니다. 정확한 일정과 개인별 자격은 학교 공식 공지 또는 담당 부서에서 확인하세요.

확인되지 않은 날짜·금액·연락처를 임의로 안내하지 않습니다.

연결 설정

변경 사항은 이 브라우저에만 저장됩니다. 제출용 기본 주소는 코드의 N8N_WEBHOOK_URL에 입력하세요.

작동 방식

질문 전송 → n8n Webhook → 질문 분류 및 답변 생성 → JSON 응답 → 화면 표시

워크플로우 JSON 다운로드
웹사이트 제작 실습 · 실제 서비스가 아닌 수업용 프로젝트
